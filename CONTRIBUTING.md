# Contribuindo

Sugestões e correções são bem-vindas.

1. Crie uma issue descrevendo o problema ou melhoria.
2. Faça um fork e crie uma branch para a alteração.
3. Evite alterar as fórmulas sem documentar a justificativa e os casos de teste utilizados.
4. Teste a interface em desktop e mobile antes de abrir um pull request.
