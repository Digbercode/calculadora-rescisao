Entenda os cálculos

13º salário proporcional

Considera os meses do ano do desligamento conforme a lógica adotada na planilha, incluindo a regra de 15 dias.

Férias

O valor usa salário ÷ 12 × meses considerados, descontando 12 meses para cada período informado em “Quantidade de férias tiradas”. O adicional de 1/3 é mostrado separadamente.

FGTS e multa

O saldo acumulado exibido é uma estimativa. O extrato oficial do FGTS continua sendo a referência para conferência.

Descontos

A versão 1.5 segue os parâmetros do modelo fornecido: INSS de 8%, vale-transporte de 7%, alimentação de 10%, IRRF estimado e outros descontos zerados.

Sobre este projeto

A ideia nasceu para transformar uma planilha de rescisão em uma ferramenta mais fácil de usar no celular ou computador. O objetivo é ajudar na organização e compreensão dos valores, não substituir documentos oficiais nem uma análise profissional.

Os cálculos desta versão reproduzem a lógica do arquivo-modelo usado no desenvolvimento. Como regras trabalhistas e tributárias podem variar ou mudar, confira os resultados antes de tomar decisões com base neles.

Perguntas frequentes

O resultado é oficial?

Não. É uma estimativa para facilitar a compreensão e a conferência inicial da rescisão.

Por que o FGTS aparece como estimativa?

O saldo real depende dos depósitos efetivamente realizados. Para confirmação, consulte o extrato oficial.

Meus dados são enviados para algum servidor?

Nesta versão, os cálculos acontecem no próprio navegador e o projeto não possui cadastro ou banco de dados para guardar os valores preenchidos.

Posso imprimir meu resultado?

Sim. Use o botão “Imprimir / salvar em PDF” e escolha a opção de PDF na janela de impressão do navegador.
